========================================
  HUONG DAN CHAY UNG DUNG - COSMETICS STORE
========================================

BUOC 1: CAI NODE.JS (chi 1 lan)
--------------------------------
Tai tai https://nodejs.org (ban 18 tro len), cai dat xong mo lai cua so lenh.
Kiem tra:   node -v


BUOC 2: CAI THU VIEN (chi 1 lan)
--------------------------------
Mo CMD / PowerShell tai thu muc du an va chay:

    npm install


BUOC 3: CHAY UNG DUNG
---------------------
    npm start

Mo trinh duyet vao:  http://localhost:3000
Dung chuong trinh:   bam Ctrl + C trong cua so lenh.

(Lenh nay vua phuc vu trang web, vua lam API du lieu tu src/db.json.
 KHONG mo file index.html bang cach nhap dup.)


TAI KHOAN DUNG THU
------------------
- Khach hang: tu dang ky o nut "Dang nhap / Dang ky" tren header.
- Quan ly: xem muc "Tai khoan de dung thu" trong README.md.
- Ma giam gia mau: WELCOME10, FREESHIP, GIAM50K


LOI THUONG GAP
--------------
- "Khong the tai danh sach san pham": chua chay npm start.
- "EADDRINUSE": cong 3000 dang bi chuong trinh khac dung, tat no roi chay lai.
- Sua code khong thay doi: bam Ctrl + Shift + R tren trinh duyet.

Huong dan day du, cau hinh ma QR chuyen khoan va email: xem README.md
