BƯỚC 1: CÀI ĐẶT JSON-SERVER
----------------------------
Mở Command Prompt (CMD) hoặc PowerShell và chạy:

    npm install -g json-server

Hoặc đơn giản hơn, chạy file: START_SERVER.bat


BƯỚC 2: KHỞI ĐỘNG SERVER
-------------------------
Chạy file: START_SERVER.bat

Hoặc mở CMD/PowerShell tại thư mục dự án và chạy:

    json-server src/db.json --port 3000

Server sẽ chạy tại: http://localhost:3000


BƯỚC 3: MỞ ỨNG DỤNG
--------------------
Có 2 cách:

CÁCH 1: Chạy file OPEN_APP.bat

CÁCH 2: Sử dụng Live Server (VS Code)
   - Cài extension "Live Server" trong VS Code
   - Click chuột phải vào file index.html
   - Chọn "Open with Live Server"

CÁCH 3: Sử dụng Python
   - Mở CMD/PowerShell tại thư mục dự án
   - Chạy: python -m http.server 8000
   - Truy cập: http://localhost:8000


KIỂM TRA API
------------
Sau khi chạy json-server, bạn có thể kiểm tra API:

- Tất cả sản phẩm: http://localhost:3000/products
- Sản phẩm theo ID: http://localhost:3000/products/1
- Đánh giá: http://localhost:3000/reviews

HỖ TRỢ
------
Nếu gặp vấn đề, kiểm tra:

3. Port 3000 có bị chiếm không?
